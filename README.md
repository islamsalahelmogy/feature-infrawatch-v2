# InfraWatch V2

Enterprise infrastructure-monitoring foundation for a multi-factory LAN deployment. Phase 1 provides Laravel 11 authentication, role-based access control, site/device inventory, monitoring-profile configuration, and worker-health visibility.

Read [PROJECT_STATUS.md](PROJECT_STATUS.md) for the current scope, [DEPLOYMENT.md](DEPLOYMENT.md) for setup, and [IMPLEMENTATION_ROADMAP.md](IMPLEMENTATION_ROADMAP.md) for planned monitoring functionality.
